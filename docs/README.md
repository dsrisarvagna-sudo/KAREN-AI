# Karen AI

Karen AI is a modular desktop AI assistant built in Python.

Unlike a traditional chatbot, Karen is designed as a personal operating system assistant capable of understanding natural language, controlling desktop applications, remembering user preferences, and assisting with software development.

# Karen AI Philosophy

Karen is a privacy-first, local-first desktop AI companion designed to help Sarvagna become an exceptional software engineer.

Karen is built with the following principles:

- Privacy First
- Local AI whenever possible
- Modular Architecture
- Human-in-the-loop decisions
- Explain before changing code
- Learn continuously
- Extensible through skills and plugins

Karen is not just an assistant.
She is a long-term engineering companion.

## Current Features
